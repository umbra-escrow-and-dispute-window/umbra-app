# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

The Umbra project takes the security of smart contracts, off-chain hashing, and user interfaces seriously.

If you discover a security vulnerability in this repository:

1. **Do not open a public GitHub issue.**
2. Send an email to the repository maintainer at `olorunfemiamos87@gmail.com` with:
   - Description of the vulnerability
   - Steps to reproduce or proof-of-concept
   - Potential impact on smart contract funds or state integrity
3. We will acknowledge receipt within 48 hours and coordinate remediation before public disclosure.

Thank you for helping keep Umbra and its users safe!
